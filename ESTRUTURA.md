# ESTRUTURA.md - Joguinho-em-Python

## Visão Geral
Mini-jogo desenvolvido em Python, focado em lógica de programação e interação via terminal ou interface gráfica leve.

## Organização de Pastas
- `src/` ou arquivos principais `.py`: Código fonte da mecânica do jogo.
- `tests/`: Bateria de testes unitários.
- `.github/workflows/`: CI para execução de testes automatizados (pytest).

## Arquitetura e Fluxo de Dados
Arquitetura procedural/orientada a objetos em Python com loop principal de jogo (*game loop*) e validação de entradas.
